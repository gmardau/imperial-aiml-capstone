### Hyperparameter effects: What are some key hyperparameters you have used or observed in neural networks? How did changing these affect your model’s convergence, stability or performance?
The most common, or rather discussed, hyperparameters in neural networks are the learning rate, the architecture of the network (the number of layers and the number of neurons in each layer), and the activation function. The most consequential one is likely the learning rate, as it quickly affects all three properties; set it too low and the network will be badly trained, or require imense datasets, set it too high and the weight parameters keep diverging. The architecture of the network also impacts its training and performance; if the network is too small, it could fail to converge, and likely underfit; if too large, gradients could either vanish or explode, or it could easily overfit and not achieve good performance on new data. Another key hyperparameter is the activation function itself, affecting convergence and stability. Some activation functions, like the traditional sigmoid, suffer from vanishing gradients at certain input values (e.g.: for sigmoid, very large positive or negative inputs), which can cause neurons to barely update, delaying convergence. Others, like the standard ReLU, suffer from "dying" problems, where a neuron can get stuck at a value of 0, effectively reducing the network capacity (almost as if its architecture was shrunk).

### Discrete vs continuous: Categorise the hyperparameters you’ve worked with. Which are continuous and which are discrete? How might the type of hyperparameter influence the method used to tune it?
Here, we have not just two types of hyperparameters, but three: continuous, of which the learning rate is an example; discrete ordinal, of which the network architecture is an example; and discrete categorical, of which the activation function is an example. For continuous hyperparameters, one could use GP surrogates to perform tuning. However, GP might not be the most well suited for discrete hyperparameters. It could still handle discrete ordinal hyperparameters, although that would break the assumption that the function is smooth; it's in fact stepped. For discrete categorical hyperparameters, there is no "distance" between parameters, so any GP surrogate would need to be heavily modified, e.g.: with one-hot encoding or Hamming-distance based kernels to preprocess the data. For discrete hyperpameters, other methods such as random forests or evolutionary algorithms (population-based training) could instead be used.
